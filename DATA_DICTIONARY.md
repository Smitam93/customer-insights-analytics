# Synthetic data dictionary

All sample values, entities and dates are independently invented. See DATA_POLICY.md.

## feedback.csv

Rows: 1,800. Generated by `run.py`; no missing input values.

| Field | Stored type | Definition |
|---|---|---|
| feedback_id | object | Unique synthetic feedback key. |
| template_family | int64 | Integer phrase family 0–3; family 3 held out. |
| channel | object | Synthetic communication or acquisition channel; these are separate populations. |
| text | object | Invented short English customer feedback; no real customer text. |
| topic_label | object | Synthetic ground truth, unavailable to model features; payments/login/fees/support/applications. |
| sentiment_label | object | Synthetic ground truth, unavailable to model features; negative/neutral/positive. |
| split | object | Train/validation randomized in pricing; train/test by phrase family in text. |

## sessions.csv

Rows: 6,000. Generated by `run.py`; no missing input values.

| Field | Stored type | Definition |
|---|---|---|
| session_id | object | Unique synthetic website session key. |
| channel | object | Synthetic communication or acquisition channel; these are separate populations. |
| is_mobile | int64 | 1 = mobile; 0 = desktop. |
| product_view | int64 | 0/1 session reached product page. |
| add_to_cart | int64 | 0/1 session added product; implies product_view. |
| purchase | int64 | 0/1 session purchased; implies add_to_cart. |
| revenue_usd | float64 | For pricing: converted * total_price_usd; for geo: conversions * $80; for sessions: basket value if purchased. |
